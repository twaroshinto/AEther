# AEther

A PaulStretch-style spectral synthesizer for the M-VAVE FM-1: every sound becomes an endless, slowly moving cloud.
Version {{VERSION}}.

> [NOTICE](https://github.com/twaroshinto/AEther/blob/main/NOTICE) first.

## Install

**[Install on your FM-1](install/)**: Chrome or Edge, the FM-1 on a USB cable, one button. When it is done,
**switch the FM-1 off and on again**: without a full restart the sound can drop out.
The firmware file itself: [{{PKG}}](firmware/{{PKG}}).

## Try it first

**[AEther in the browser](emu/)**: the same firmware, emulated, with sound. Play it with the computer keyboard.

## Edit

**[The AEther editor](editor/)**: every parameter at once, the spectrum, the matrix and what modulation does right
now; store your sounds as user presets on the FM-1 (Chrome or Edge, the FM-1 on USB).

## Read

**[The user manual](manual/)**: every knob, page and preset, with pictures.

## Going back

To go back to M-VAVE's firmware, use the installer's "Back to the stock firmware", or M-VAVE's own updater,
M-UPGRADE.
